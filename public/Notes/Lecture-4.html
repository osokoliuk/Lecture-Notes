Definition DG4.1(Definition).

A subset S of R3 is a regular surface if ∀p∈S, ∃ an open set V⊂R3 such that p∈V and ∃X:U↦V where U is an open set of R2, X is surjective and

  1. X is a C∞ map.
  2. X is a homeomorphism between open sets U and V.
  3. ∀q∈U, dXq​:R2↦R3 is injective.

We call X a local chart around p while V∩S is called a coordinate chart of S around p.

Remark DG4.2(Remark).

dXq​(v) is the differential of X around a point q and is defined as:

dXq​(v)=dtd​​t=0​(X∘α)(t)

with α:{−ϵ,ϵ}↦R2, ϵ>0, defined by α(0)=q and α′(0)=v.

Proposition DG4.3(Proposition).

f:U↦R is a C∞ function. The graph of this function, Γf​={u,v,f(u,v):(u,v)∈U} is a regular surface.

Proof.

Take X(u,v)=(u,v,f(u,v)). By construction, this function is one-to-one. It is also C∞ and surjective, by the definition of f, Hence, X−1 exists. Moreover, X−1 is C∞ as it is a restriction of Γf​ to (x,y,z)→(x,y). Now, note that dXq​ is injective iff

∂u∂X​∧∂v∂X​=0

Hence, those two partial derivatives must be linearly independent. But

∂u∂X​=(1,0,∂u∂f​)∂v∂X​=(0,1,∂v∂f​)

which proves the linear independence of those two vectors, making dXq​ injective.□

Example DG4.4(Example).

Consider a unit sphere at the origin S2={(x,y,z):x2+y2+z2=1}.

Let

X1​(x,y)={x,y,1−x2−y2​:x,y∈U1​}X2​(x,y)={x,y,−1−x2−y2​:x,y∈U2​}X3​(x,z)={x,1−x2−z2​,z:x,z∈U3​}X4​(x,z)={x,−1−x2−z2​,z:x,z∈U4​}X5​(y,z)={1−y2−z2​,y,z:y,z∈U5​}X6​(y,z)={−1−y2−z2​,y,z:y,z∈U6​}

Those charts now cover the whole of S2, hence a sphere is a regular surface.

Theorem DG4.5(Implicit Function Theorem).

Let O be an open set of R3, p=(x0​,y0​,z0​)∈R3, a∈R and f:O↦R is a C∞ function. Suppose that f(p)=a, ∂z∂f​(p)=0. Then, ∃ an open set U⊂R2 such that (x0​,y0​)∈U and an open set V⊂R such that z0​∈V, a function g:U↦V defined by g(x0​,y0​)=z0​ with U×V⊂O and {p∈U×V:f(p)=a}={(x,y,g(x,y)):(x,y)∈U}.

Corollary DG4.6(Corollary).

Let a∈R be a regular value for a C∞ function (i.e. dfp​=0∀p∈f−1(a))), then f−1(a) is either empty or a regular surface.

Proof.

Let p=(x0​,y0​,z0​)∈f−1(a). By assumption, a is a regular value and hence dfp​=0. Assume without the loss of generality that ∂z∂f​(p)=0. Implicit function theorem implies that for S=f−1(a), S∩(U×V) is a regular surface. Since we have a freedom to choose any point p and a is a regular value, we can construct as many charts as we need to cover the whole f−1(a), hence it is a regular surface.□
